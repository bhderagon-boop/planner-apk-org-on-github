# پلنر هوشمند — نسخه اندروید

همان پلنر (طراحی، تقویم شمسی، نمودارها، خروجی CSV/JSON) به‌صورت برنامه‌ی اندروید، با Capacitor.

## ساخت APK
پیش‌نیازها: Node.js 22+، JDK 21، Android Studio (یا Android SDK با API 36).

1. `build_apk.bat` را اجرا کنید (در لینوکس/مک: `./build_apk.sh`).
2. فایل APK اینجا ساخته می‌شود: `android/app/build/outputs/apk/debug/app-debug.apk`
3. آن را به گوشی بفرستید و نصب کنید (نصب از منبع ناشناس باید مجاز باشد).

یا: `npm install` ← `npm run sync` ← پوشه‌ی `android` را در Android Studio باز کنید ← Run ▶.

## قابلیت‌های اندرویدی
- یادآوری با اعلان: ساعت ۹ صبحِ روز قبل و ۹ صبحِ روز سررسید (برای تسک‌های انجام‌نشده)
- دکمه‌ی «تقویم گوشی»: تسک‌ها به‌صورت رویداد تمام‌روز در تقویم گوشی ثبت/به‌روز/حذف می‌شوند
- رویدادهای تقویم گوشی در تقویم شمسی پلنر نمایش داده می‌شوند (فقط‌خواندنی)
- خروجی CSV/JSON و دکمه‌ی اشتراک ← برگه‌ی اشتراک‌گذاری اندروید
- دکمه‌ی برگشت: بستن پنجره ← بازگشت به تب تسک‌ها ← خروج
- کاملاً آفلاین (فونت، آیکن و نمودار داخل برنامه‌اند)

## ساختار
- `web/`  صفحه‌ی پلنر (index.html + assets)
- `src/native.js`  پل اندروید (اعلان، تقویم، اشتراک فایل)
- `build-web.js`  web ← www و بسته‌بندی native.js
- `android/`  پروژه‌ی اندروید (Gradle)

بعد از هر تغییر در `web/` یا `src/`: `npm run sync`
